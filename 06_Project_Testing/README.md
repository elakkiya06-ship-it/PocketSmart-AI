# Phase 6 – Project Testing

## 1. Project Name

**PocketSmart AI – Smart Budget & Recommendation Assistant**

## 2. Testing Objective

The objective of this phase is to verify that PocketSmart AI works correctly and that its major features perform as expected.

Testing was carried out to identify errors, incorrect inputs, navigation problems and application issues.

## 3. Testing Approach

The application was tested by checking individual features and then testing the complete application workflow.

The following areas were tested:

* User registration
* User login
* Dashboard
* Recommendation form
* AI recommendation generation
* Recommendation result
* Recommendation details
* History
* Navigation
* Error handling
* Responsive interface
* Online deployment

## 5. Functional Testing

Functional testing was performed to verify that the main features work according to the project requirements.

### Authentication

Registration and login functionality were tested using valid and invalid inputs.

### Recommendation

The recommendation form was tested by providing different user requirements and budget information.

### AI Recommendation

The AI integration was tested to verify that recommendations are generated and displayed correctly.

### History

The history feature was tested to verify that previous recommendation information can be accessed.

## 6. Input Validation Testing

Different input conditions were checked, including:

* Empty fields
* Invalid values
* Missing required information
* Valid user inputs

The application provides appropriate responses when incorrect or incomplete information is submitted.

## 7. UI Testing

The user interface was checked for:

* Proper alignment
* Readable text
* Working buttons
* Working navigation links
* Form layout
* Responsive design
* Consistent styling

## 8. Deployment Testing

The deployed application was opened through the Render URL and the major application features were checked in the online environment.

## 9. Bug Identification

During development and testing, application issues were identified and corrected where required.

Testing helped verify that the major workflows of the application operate correctly.

## 10. Final Testing Result

The major features of PocketSmart AI were tested successfully.

The application was found to be functional for the intended project workflow.

## 11. Conclusion

The Project Testing phase verified the functionality, usability, navigation, input handling and deployment of PocketSmart AI. Testing helped ensure that the application was ready for documentation and final demonstration.
