# Phase 1 – Brainstorming & Ideation

## Project Name

PocketSmart AI – Smart Budget & Recommendation Assistant

## Problem Statement

Many students and young users find it difficult to manage their limited budget and make suitable spending decisions. They may not know how to plan their expenses or choose affordable options.

## Proposed Solution

PocketSmart AI is a web-based AI assistant that provides personalized budget planning and recommendations based on the user's requirements and available budget.

## Target Users

* College students
* Young adults
* Users with limited budgets
* Anyone who wants simple budget planning assistance

## Main Idea

The system collects relevant user information and generates AI-powered recommendations focused on practical and budget-friendly decisions.

## Expected Benefits

* Helps users plan their spending
* Provides personalized recommendations
* Saves time when making decisions
* Encourages budget-conscious spending
* Provides a simple web-based interface

## Technologies

* Python
* FastAPI
* HTML
* CSS
* JavaScript
* Google Gemini AI
* GitHub
* Render

## Outcome of Ideation

The PocketSmart AI concept was selected as a practical AI-based web application that combines budget planning with personalized recommendations.
