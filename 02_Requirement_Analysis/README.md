# Phase 2 – Requirement Analysis

## 1. Project Name

**PocketSmart AI – Smart Budget & Recommendation Assistant**

## 2. Introduction

PocketSmart AI is an AI-powered web application designed to help users make better budget-related decisions. The application collects user requirements and provides personalized recommendations based on their budget and preferences.

## 3. Problem Analysis

Users may face difficulty when:

* Planning their available budget
* Deciding how to spend money wisely
* Finding suitable options within a limited budget
* Comparing different choices
* Managing expenses effectively

## 4. Proposed System

PocketSmart AI provides a simple web-based platform where users can enter their requirements and receive AI-generated recommendations.

The system uses Google Gemini AI to generate personalized responses based on the information provided by the user.

## 5. Functional Requirements

The system should allow users to:

1. Register and log in.
2. Access the dashboard.
3. Enter their budget and requirements.
4. Generate AI-powered recommendations.
5. View recommendation details.
6. View previous recommendation history.
7. Navigate between different sections of the application.
8. Log out securely.

## 6. Non-Functional Requirements

The application should provide:

* Simple and user-friendly interface
* Responsive design
* Fast response
* Secure handling of user information
* Reliable AI recommendation generation
* Easy navigation
* Clear and readable results

## 7. Hardware Requirements

### Minimum Requirements

* Computer or laptop
* 4 GB RAM or above
* Internet connection
* Modern web browser

## 8. Software Requirements

* Windows / Linux / macOS
* Python
* FastAPI
* HTML
* CSS
* JavaScript
* Google Gemini AI
* Git
* GitHub
* Web browser

## 9. Technology Stack

| Component       | Technology                          |
| --------------- | ----------------------------------- |
| Frontend        | HTML, CSS, JavaScript               |
| Backend         | Python, FastAPI                     |
| AI              | Google Gemini AI                    |
| Version Control | Git & GitHub                        |
| Deployment      | Render                              |
| Database        | Project-configured database/storage |

## 10. User Requirements

The user should be able to:

* Create an account
* Log in to the application
* Enter budget-related information
* Request recommendations
* Read AI-generated recommendations
* Access previous results
* Log out from the application

## 11. System Requirements

The system requires:

* Python environment for backend execution
* FastAPI server
* Internet connection for AI service requests
* Gemini API configuration
* Web browser for accessing the application

## 12. Expected Result

The completed system should provide users with personalized, practical and budget-focused recommendations through an easy-to-use web application.

## 13. Conclusion

The requirement analysis identifies the major functional, non-functional, hardware and software requirements needed to develop PocketSmart AI. These requirements will be used as the foundation for the project design and development phases.
