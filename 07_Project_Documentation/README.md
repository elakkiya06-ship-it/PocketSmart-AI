# Phase 7 – Project Documentation

## 1. Project Name

**PocketSmart AI – Smart Budget & Recommendation Assistant**

## 2. Project Overview

PocketSmart AI is an AI-powered web application designed to provide personalized recommendations based on user requirements and budget.

The system collects relevant information from the user and uses artificial intelligence to generate useful and practical recommendations.

## 3. Problem Statement

Users often spend time searching for suitable options based on their requirements and available budget.

PocketSmart AI aims to simplify this process by providing personalized recommendations through an AI-powered web application.

## 4. Objectives

The main objectives of PocketSmart AI are:

* To provide personalized recommendations.
* To consider the user's budget.
* To reduce the time required for searching and comparing options.
* To provide practical suggestions using AI.
* To provide a simple and user-friendly interface.
* To maintain previous recommendation information.

## 6. Main Features

### User Authentication

Users can register and log in to access the application.

### Dashboard

The dashboard provides access to the major features of PocketSmart AI.

### AI Recommendations

The system generates recommendations based on the information provided by the user.

### Budget-Focused Suggestions

Recommendations are generated while considering the user's budget requirements.

### Recommendation Details

Users can view additional information related to their generated recommendations.

### History

Previous recommendation information can be accessed through the history section.

### Responsive Interface

The application interface is designed to work on different screen sizes.

## 7. System Workflow

```text
User
  ↓
Registration / Login
  ↓
Dashboard
  ↓
Enter Requirements & Budget
  ↓
Backend Processing
  ↓
Google Gemini AI
  ↓
Generate Recommendation
  ↓
Display Result
  ↓
Save / View History
```

## 8. User Workflow

1. Open PocketSmart AI.
2. Register an account if the user is new.
3. Log in to the application.
4. Open the dashboard.
5. Enter the required information.
6. Provide budget-related details.
7. Submit the recommendation request.
8. The backend processes the request.
9. Gemini AI generates the recommendation.
10. The recommendation is displayed to the user.
11. The user can view additional details.
12. Previous recommendations can be accessed through History.

## 9. Advantages

* Easy to use.
* AI-powered recommendations.

* Saves time during decision-making.
* Provides practical information.

## 10. Limitations

* AI-generated recommendations may not always be completely accurate.
* Actual prices and availability may change.
* Internet connectivity may be required for online AI services.
* Recommendations depend on the information provided by the user.
